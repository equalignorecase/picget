# Picget

เดสก์ท็อปของคุณ รูปภาพของคุณ

Picget เป็นแอปวิดเจ็ตรูปภาพบนเดสก์ท็อปแบบเนทีฟสำหรับ macOS บน Apple Silicon และ macOS 14 ขึ้นไป พัฒนาด้วย AppKit, SwiftUI, Core Animation, ImageIO และ Foundation โดยไม่มีไลบรารีจากบุคคลที่สาม

## การบิลด์และติดตั้ง

เปิด `Picget.xcodeproj` ใน Xcode หรือรันคำสั่ง:

```sh
xcodebuild -project Picget.xcodeproj -scheme Picget -configuration Release \
  -destination 'platform=macOS,arch=arm64' -derivedDataPath build build
```

ไฟล์แอปที่บิลด์จาก Xcode จะอยู่ที่ `build/Build/Products/Release/Picget.app` หากมีเพียง Apple Command Line Tools ให้รัน `./Scripts/build-release.sh` เพื่อสร้างไฟล์ `build/Picget.app` ที่ลงนามในเครื่อง คัดลอกไฟล์แอปจากวิธีใดวิธีหนึ่งไปยังโฟลเดอร์ Applications แล้วเปิดใช้งาน จากนั้นตั้งค่า Launch at Login หลังจากติดตั้งแอปเรียบร้อยแล้ว

## การใช้งาน

- เปิด **Add Widget** จากหน้าต่างจัดการหรือแถบเมนู เลือกไฟล์ PNG, JPEG หรือ GIF วาง URL รูปภาพแบบ HTTPS หรือลากไฟล์รูปภาพในเครื่องมาวางลงในรายการวิดเจ็ต
- ลากวิดเจ็ตที่ปลดล็อกอยู่เพื่อย้ายตำแหน่ง ลากมุมขวาล่างเพื่อปรับขนาด และลากไฟล์มาวางบนวิดเจ็ตเพื่อเปลี่ยนรูปภาพ
- เลือกวิดเจ็ตจากรายการเพื่อปรับค่าความทึบแสง ความโค้งมนของมุม การจัดวางภาพ (fit/fill) การครอบตัด (crop) การโต้ตอบ และจังหวะเวลาของ GIF
- ใช้ **Edit Desktop** หรือ **Toggle Edit Widgets** บนแถบเมนูเพื่อเรียกคืนการแก้ไขวิดเจ็ตที่ตั้งค่าให้คลิกทะลุได้ (click-through) ทั้งนี้วิดเจ็ตที่ตั้งค่าความทึบแสงเป็นศูนย์ยังคงแก้ไขได้จากรายการ
- ใช้ **Refresh Image** เพื่ออัปเดตรูปภาพจากอินเทอร์เน็ตด้วยตนเอง รูปภาพที่นำเข้าไว้แล้วสามารถใช้งานแบบออฟไลน์ได้
- เปิด **Settings** เพื่อเปลี่ยนโหมดแอป การเริ่มต้นทำงาน รูปลักษณ์ การตั้งค่าเปิดแอปเมื่อเข้าสู่ระบบ หรือ Low Power Mode

## การจัดเก็บข้อมูลและประสิทธิภาพ

Picget จัดเก็บไฟล์รูปภาพและการตั้งค่า JSON ไว้ใน `~/Library/Application Support/Picget` แอปจะเชื่อมต่อกับเซิร์ฟเวอร์เฉพาะเมื่อมีการสั่งนำเข้าหรือรีเฟรชรูปภาพเท่านั้น ไม่มีการเก็บข้อมูลวิเคราะห์ (analytics) บัญชีผู้ใช้ หรือการซิงโครไนซ์ โดย URL ต้นทางจะถูกเก็บไว้ในเครื่องสำหรับการรีเฟรชด้วยตนเอง

วิดเจ็ตภาพนิ่งจะเก็บภาพในเลเยอร์ไว้และอัปเดตเมื่อจำเป็น ส่วนไฟล์ GIF จะใช้ตัวจับเวลาแบบ deadline ร่วมกัน การถอดรหัส ImageIO จะทำงานแบบเรียงลำดับนอก main actor และแคชของภาพที่ถอดรหัสแล้วจะจำกัดขนาดตามงบประมาณหน่วยความจำ (byte budget)
